Alerta de Enchentes
com Arduino Uno

Guia educativo para conhecer os materiais, as ligações, a programação e os testes de um protótipo de monitoramento da água.

SobreMateriaisLigaçõesCódigoTestesCuidados

1. Sobre o projeto

O protótipo demonstra como um sensor pode acompanhar a presença e a variação da água e como um Arduino pode acionar avisos visuais e sonoros.

Importante: este é um protótipo educativo. Não prevê enchentes nem substitui estações profissionais, previsões meteorológicas ou alertas da Defesa Civil.

2. Materiais

  • Arduino Uno R3 e cabo USB;
  • Sensor de água de 3 pinos (SIG/S, VCC e GND);
  • Protoboard e fios jumper;
  • LED verde, amarelo e vermelho;
  • 3 resistores de 220 Ω ou 330 Ω, um por LED;
  • Buzzer ativo de 5 V e 2 pinos;
  • LCD 16×2 com módulo I²C;
  • Recipiente plástico para demonstração.

Confira as identificações dos pinos dos seus próprios componentes. Um buzzer de 3 pinos pode exigir ligação diferente.

Atenção aos resistores: cada LED precisa do seu próprio resistor em série. Não coloque as duas pernas do LED na mesma fileira eletricamente conectada da protoboard.

Na protoboard comum, cada grupo de cinco furos de um lado da canaleta central é conectado internamente. Os dois lados da canaleta são isolados. As trilhas de alimentação podem ter interrupções; confira sua placa.

4. Código de exemplo

O exemplo usa LCD I²C no endereço 0x27 e a biblioteca LiquidCrystal I2C (Frank de Brabander). Os limites 300 e 600 são apenas valores iniciais de demonstração e precisam ser ajustados com as leituras do sensor real.

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int sensor = A0;
const int verde = 2, amarelo = 3, vermelho = 4, buzzer = 5;

void setup() {
  pinMode(verde, OUTPUT);
  pinMode(amarelo, OUTPUT);
  pinMode(vermelho, OUTPUT);
  pinMode(buzzer, OUTPUT);
  lcd.init();
  lcd.backlight();
  Serial.begin(9600);
}

void loop() {
  int leitura = analogRead(sensor);
  Serial.println(leitura);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Nivel: ");
  lcd.print(leitura);

  digitalWrite(verde, LOW);
  digitalWrite(amarelo, LOW);
  digitalWrite(vermelho, LOW);
  digitalWrite(buzzer, LOW);

  if (leitura < 300) {
    digitalWrite(verde, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Situacao segura");
  } else if (leitura < 600) {
    digitalWrite(amarelo, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Atencao");
  } else {
    digitalWrite(vermelho, HIGH);
    digitalWrite(buzzer, HIGH);
    lcd.setCursor(0, 1);
    lcd.print("Alerta maximo!");
  }
  delay(500);
}

Abra o Monitor Serial, observe os valores com o sensor seco e em diferentes contatos com água e ajuste os limites. Se a leitura diminuir quando molha, inverta a lógica. Os valores não representam alturas oficiais de rios.

5. Como testar

  1. Desconecte o Arduino antes de mudar qualquer fio.
  2. Confira polaridade dos LEDs, resistores e pinos dos módulos.
  3. Mantenha Arduino, protoboard e conexões longe do recipiente com água.
  4. Ligue por USB e observe a leitura no Monitor Serial.
  5. Aproxime o sensor da água gradualmente, sem molhar a placa eletrônica.
  6. Registre as leituras e ajuste as faixas demonstrativas.
  7. Confira se cada LED acende separadamente e se o buzzer funciona na faixa definida.

6. Cuidados e limitações

  • Não mergulhe Arduino, protoboard ou LCD na água.
  • Use baixa tensão e mantenha as mãos secas.
  • O sensor resistivo pode sofrer corrosão se permanecer molhado.
  • Seque o sensor após a demonstração.
  • Para uso real seriam necessários sensores adequados, calibração, proteção contra intempéries, energia de reserva e validação técnica.
